### 手测（本机 Chrome）

1. `bun run dev` → Composer 可见 **Ask | Auto**（默认 Ask）。
2. Ask：让 Agent 写文件 / 跑命令 → 出现「需要审批」卡片 → **拒绝** → 磁盘无文件 / 命令未执行。
3. 再发一次 → **允许** → 流继续且副作用落地。
4. 切 **Auto**（或设置「无需审批」）→ 同类写入无 pending 卡。
