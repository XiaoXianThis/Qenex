# M5 完成记录 — 模式 / 模型 / Session config

**状态：通过**（2026-08-03）

## 范围（对照 [`重构指导.md`](../../重构指导.md) §M5）

1. Bridge REST（经 ACP `provider.setMode` / `setModel`）：
   - `GET /api/sessions/:id/config`（`ensureOpen` 后返回；重启后也会从 ACP 刷新目录）
   - `POST /api/sessions/:id/mode` `{ modeId }`
   - `POST /api/sessions/:id/model` `{ modelId }`
2. **ACP 目录来源**：优先 legacy `modes`/`models`；OpenCode 当前走 `configOptions`（`category: mode|model`）→ 归一进 SessionInfo（见 `acp-session-config.ts`）。
   - `session/load`（重启重连）常不带 `configOptions`：优先用 SQLite 已存目录；否则 cwd 级 cache / throwaway `session/new` probe 回填。
3. 前端 `SessionConfigContext`：bootstrap / refresh / changeMode / changeModel 走 `aisdk-session`（不再打 `/v2/tasks`）。
4. `SessionConfigBar`（中文 mode 映射）在 `config.ready` 且有 modes/models 时显示。
5. **无** `ModeSyncBridge` / AG-UI `mode_update`（不重建 SSE）。
6. thought/fast：若 Agent 广告 `thought_level` configOption 则灌入 DTO；OpenCode 通常无 → 空；非硬性验收。
