**状态：通过**（2026-08-03）

## 范围（对照 [`重构指导.md`](../../../重构指导.md) §M3）

1. Bun Bridge：`GET /api/files?base=&path=`，realpath + `isWithin` 防 cwd 逃逸。
2. fusion `@`：`ComposerAutocomplete` 挂回自定义 textarea（**本地 draft** + `listWorkspaceFiles`）。
3. 附件：`useAISDKRuntime({ adapters: { attachments: createComposerAttachmentAdapter() } })` + `ComposerPrimitive.Root`；发送时 `useAui().composer().setText(draft)` → `send()` 带多模态 parts。
4. 富消息：`ActiveThreadLayout` 改回 `ThreadMessagesArea`（Markdown / Reasoning / 工具卡 / Shiki / Mermaid）；退役主路径 `AisdkThreadMessages`。
5. 只读 artifacts：`parseMessageMetadata` + `MessageArtifacts`（plan / diff / terminal）。

### Composer 设计注

`ComposerPrimitive.Input` / `unstable_useComposerInput` 在 `useChat` + `useAISDKRuntime` 下文本不可靠（与 next 同结论）。因此：

- 输入框用 React `useState` 本地 draft；
- `@` Popover 受控于该 draft；
- 发送时把 draft 写入 thread composer，再 `send()`，以便附件 parts 一并进入 UIMessage。
