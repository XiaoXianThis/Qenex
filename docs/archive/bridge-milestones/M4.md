1. **统一 ID**：Tab 字段 `taskId` → `sessionId`（hydrate 迁移旧 localStorage）；Runtime `threadId` = Bridge `ses_…`。
2. **Bridge SQLite**：默认 `~/.qenex/sessions.db`（`QENEX_SESSIONS_DB` 可覆盖）；存 session 元数据 + UIMessage（parts/metadata）。
3. **API**：
   - `GET /api/sessions` / `GET :id` 可读冷启动（DB）会话
   - `GET /api/sessions/:id/messages` 拉历史

   - `DELETE` 删内存 + DB；之后 chat/messages → 404
   - `POST /api/chat`：`ensureOpen`（`existingSessionId` 重连）+ `onEnd` 落库
4. **前端**：bootstrap 拉历史 → `useChat({ messages: initialMessages })`；**无** AG-UI event replay / `tasks.db`。
5. **重置规则**：清 `~/.qenex/sessions.db`（及 wal/shm）；旧 `tasks.db` 仍可删。
